## 2. 认证与权限模块（本批次不实现）

> ⚠️ 后端 `rpm-iam` 模块**没有 HTTP Controller**（无 `/auth/login`、`/iam/users` 等端点）。认证由**院方统一身份系统**（SSO/CAS/LDAP）完成，后端通过 `AuthContextHolder.require()` 解析已认证的 `AuthContext`。
>
> 前端只需要：
> 1. 提供登录入口，跳转院方 SSO 登录页
> 2. 登录成功后保存 Token
> 3. 所有请求携带 `Authorization: Bearer {token}`
> 4. 收到 `RPM-COMMON-401` 时跳回 SSO 登录页
>
> **用户/角色/权限管理页面本批次不实现**，待后端 IAM 管理接口开发后再补充。

**动态表单示例：**

```typescript
interface ApplyFormTemplate {
  projectType: string
  fields: FormField[]
  attachments: AttachmentRequirement[]
}

interface FormField {
  key: string
  label: string
  type: 'text' | 'number' | 'date' | 'textarea' | 'select'
  required: boolean
  rules?: any[]
  options?: { label: string; value: any }[]
}

const formTemplate = ref<ApplyFormTemplate | null>(null)
const formData = ref<Record<string, any>>({})

const loadFormTemplate = async (projectType: string) => {
  formTemplate.value = await applicationApi.getFormTemplate(projectType)
  // 初始化 formData
  formTemplate.value.fields.forEach(field => {
    formData.value[field.key] = ''
  })
}
```

**API 调用：**

```typescript
// 1. 创建草稿
const createDraft = async () => {
  loading.value = true
  try {
    const res = await applicationApi.create({
      batch_id: selectedBatch.value,
      project_type: selectedProjectType.value,
      title: formData.value.title,
      dept_id: formData.value.dept_id
    })
    applicationId.value = res.application_id
    ElMessage.success('草稿创建成功')
  } finally {
    loading.value = false
  }
}

// 2. 保存草稿
const saveDraft = async () => {
  loading.value = true
  try {
    await applicationApi.saveDraft(applicationId.value, {
      form_data: formData.value,
      attachment_file_ids: uploadedFileIds.value
    })
    ElMessage.success('保存成功')
  } finally {
    loading.value = false
  }
}

// 3. 提交审批
const submit = async () => {
  await formRef.value?.validate()
  
  loading.value = true
  try {
    await applicationApi.submit(applicationId.value, {
      expected_version: currentVersion.value,
      comment: '请审阅',
      form_data: formData.value,
      attachments: uploadedFileIds.value.map((fileId: string, i: number) => ({
        purpose: attachmentPurposes.value[i],
        file_id: fileId
      }))
    }, idempotencyKey)
    ElMessage.success('提交成功')
    router.push('/applications')
  } catch (err: any) {
    ElMessage.error('提交失败：' + err.message)
  } finally {
    loading.value = false
  }
}
```

- 差异记录查看与关闭 → `POST /api/v1/finance/reconciliations/{batchId}/diffs/{diffId}/close`

**API 调用：**

```typescript
import { fundingApi } from '@/api/funding'

const handleUpload = async (file: File) => {

const handleValidate = async () => {

  ElMessage.success('校验通过')
}

const handleApply = async () => {
  await ElMessageBox.confirm('确认应用导入批次？此操作不可撤销')
  const batch = await fundingApi.applyPaymentImport(currentBatchId.value)
  ElMessage.success('应用成功')
}

// 对账批次
const batches = ref<ReconciliationBatchView[]>([])
const loadBatches = async () => {

}

// 关闭差异
const handleCloseDiff = async (batchId: string, diffId: string) => {
```
