# 科研项目管理系统 — 验证用例清单

> 用途：作为任务拆解「关联验证用例」、代码生成「先行测试」和验收回归的唯一锚点。
> 表格固定六列，不得增减；用例 ID 全局唯一且稳定。
> 场景类型只使用：正常、边界、异常。
> 预期结果必须能落到具体业务值、具体状态或具体错误码，禁止 `assertNotNull` 一类弱断言。
> 来源列同时回溯 PRD 功能编号与本文 `01-总体设计与架构.md` 的 `BR-xx`。

## 0. 执行约定

| 项 | 约定 |
|---|---|
| 测试分层 | 单元测试覆盖领域规则；集成测试覆盖接口、数据库约束、工作流适配；端到端测试覆盖跨模块主链路 |
| 测试数据 | 默认项目 `KY-2026-000456`，预算总额 `1200000.00`，设备费 `300000.00`，支出 `80000.00` |
| 金额断言 | 使用 `BigDecimal` 比较，统一两位小数；不得使用浮点近似 |
| 时间断言 | 使用固定时钟或可注入 `Clock`；过期边界按 `valid_to` 精确到秒 |
| 并发断言 | 至少两线程同时提交，最终数据库状态唯一且可用余额不小于 `0.00` |
| 证据 | 失败用例必须保留 TraceID、请求体摘要、响应体、数据库前后值和审计记录 |
